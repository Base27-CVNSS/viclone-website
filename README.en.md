## Quick Start

1. Create your own repository from this template.
2. Clone your repository locally.
3. Install dependencies with `npm install`.
4. Start a supported AI coding agent.
5. Run `/clone-website <target-url1> [<target-url2> ...]`.
6. Review, test, and customize the generated implementation.

## Supported Platforms

Claude Code, Codex CLI, OpenCode, GitHub Copilot, Kiro, Cursor, Windsurf, Gemini CLI, Cline, Roo Code, Continue, Amazon Q, and Augment Code.

## Prerequisites

- Node.js 24+
- A supported AI coding agent

## Tech Stack

- Next.js 16, React 19, strict TypeScript
- shadcn/ui + Radix UI
- Tailwind CSS v4
- Lucide React

## How It Works

The `/clone-website` workflow follows five main phases: reconnaissance, foundation, component specifications, parallel build, and assembly/QA. The agent inspects the target visually and structurally, extracts design details and assets, implements components, assembles the page, and compares the result against the reference.
